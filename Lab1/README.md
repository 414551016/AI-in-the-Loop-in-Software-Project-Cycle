這次 Week 1 Lab 的核心不是寫程式，而是讓你親自觀察：你心裡想要 AI 回答的內容，和你實際寫出的 Prompt 被 AI 解讀後產生的結果，兩者之間會有落差（Intent–Output Gap）。整個 Lab 不需要 API key、不需要環境設定，也不需要交程式碼。
